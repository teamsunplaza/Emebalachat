Emebala Chat - Changelog
========================

v0.10.1 (rerelease) - 2026-09-19
================================

This rerelease of v0.10.1 ships the fixes below under the same version
number - the version is intentionally unchanged. Patch update. What you
can do now
----------------------------------
* The local translation engine now survives setup hiccups that used to
  leave it looking "not installed": if the engine's supporting files
  cannot be deployed during setup, the installer now stops and tells you
  the install failed instead of quietly continuing, and the model
  registration file is created automatically so the engine is ready on
  first launch.
* When the local translation engine is unavailable, the notice now stays
  on screen until you close it yourself (it no longer dismisses on its
  own), and it appears immediately whenever you pick the local LLM from
  the engine menu, so you always know why a local translation did not
  happen.
* You can now point the local engine at any GGUF model you like: tray >
  Translation engine > User-selected (.gguf) > Browse. After you confirm
  the quality-not-guaranteed notice and pick a .gguf file, the model is
  registered and the engine starts using it. Models other than Hy-MT2
  are not quality-guaranteed.
* A new cloud engine option, OpenAI Compatible, lets you use any
  OpenAI-compatible API: open its settings from the engine menu, enter
  the Base URL and your API key, then either fetch the model list and
  pick one or type the model name directly. Your API key is protected
  with Windows user encryption, and only its first 6 characters are
  ever shown back to you.
* Uninstall now verifies its registry cleanup, so removing the app
  leaves no orphaned install records behind.

Further fixes in this same v0.10.1 build
---------------------------------------
* Double-clicking the tray icon no longer flips translation off and back
  on: a single click still pauses or resumes translation, and a
  double-click now only shows or hides the floating badge.
* The About window no longer clips the bottom of its feature
  descriptions in languages with longer text (German, Russian, Spanish,
  Vietnamese and others); the blocks now size themselves to the text.
* Changing your display scaling (for example 100% to 150%) re-renders
  the floating badge sharply instead of leaving its text blurred.
* After a GPU driver reset, a sleep/resume, or a driver update, the
  floating badge repaints itself instead of vanishing.
* Changing the language from the result tooltip's menu no longer pulls
  focus away from the window you were typing in - your selected text and
  caret position stay exactly where they were.
* While the OpenAI-compatible model list is being fetched, the "Get
  models" button is disabled and re-enables when the request finishes,
  so repeated clicking can no longer queue duplicate requests.
* In the user model manager, Rename and Delete are now greyed out while
  no model is selected, instead of looking clickable and doing nothing.
* Rapidly repeating F9 (or any other sound-carrying hotkey) no longer
  starts one playback thread per beep: tones queue and play in order, so
  heavy shortcut use stays smooth.
* Installing or updating Emebala Chat now merges its model registration
  into the shared registry.json atomically instead of overwriting the
  file: models registered by other Emebala products, and models you
  registered yourself, can no longer be lost - even if two installers
  run at the same time.
* Uninstalling now removes only the files this installer itself placed
  in the shared store: your own registered .gguf models, and models
  belonging to another Emebala product, are preserved. If the
  registration file cannot be read or is damaged, the uninstaller leaves
  the whole shared store untouched instead of deleting it.

v0.10.1 - 2026-09-17
====================

Patch release. What you can do now
----------------------------------
* Editing an already-translated line above your cursor (for example on
  Reddit or other forums) and pressing Enter no longer re-translates that
  line or overwrites your manual edit - only the newest line is translated.
* Pasting a sentence or URL into your post and pressing Enter translates
  just the newly typed line instead of re-translating the whole post.
* When the newest line is already the translation the app placed there,
  pressing Enter after an edit higher up now does nothing at all: no engine
  call, no whole-text re-paste. Your edit stays exactly as you left it and
  the Enter passes straight through (the old behavior could reword the
  newest line and re-paste the whole post each time).
* New text you typed or inserted further up is still intentionally left
  untranslated (older lines are never re-translated automatically), but the
  app no longer stays silent about it: a one-time notice tells you to place
  the cursor at the end of that line and press Enter.
* The built-in Cheat Sheet and the README now lead with the F9 tip: press
  F9 whenever you don't need translation, press F9 again to resume.
* Local translations now run in a small shared engine system instead of
  inside each app. A background orchestrator, Emebala.Engine.exe, keeps a
  single GPU-resident copy of the model that every installed Emebala app
  reuses (two apps no longer duplicate the model in VRAM) and hands each
  translation job to a dedicated worker process, so app crashes can never
  take the model down with them. It talks to the apps over a
  current-user-only local pipe with a per-boot security token and exits by
  itself after 10 minutes idle. With the host installed, the Auto engine
  treats it as a first-class local source (it no longer demotes straight
  to Google just because the app-folder model copy is gone). If the engine
  cannot be used - missing files, connection failure, busy, or a crash -
  the app offers a one-click repair, falls back to Google (cloud use stays
  consent-gated as before), or tells you clearly that local translation is
  unavailable; it never fails silently. Old apps and configs keep working:
  the engine answers on the version-independent pipe and the frozen
  pre-0.10.1 pipe name alike, and the new config block "engine_host"
  (enabled / spawn / idle_exit_ms) is valid - defaults need no action.
  Local model files are SHA-256 pinned, so the model itself is only
  replaced together with a matching Emebala app update.

v0.10.0 - 2026-09-12 (Initial Release)
======================================

Emebala Chat translates selected text in real time and types the result
back into the original input field - even over locked screens or inside
other apps. It runs quietly from the system tray and never interferes
with the host app's normal typing or autocomplete.

What you can do now
-------------------
* Select any text, press the hotkey (or scroll-lock chord), and the
  translation is reviewed and re-typed into your app automatically.
* Choose your engine per run: Google Translate (online) or a built-in
  local LLM (Hy-MT2-1.8B) that keeps work fully offline.
* Use the app in any of 37 interface languages, switched live from the
  tray menu.
* Read the built-in Cheat Sheet (F1-style popup) for shortcuts and the
  location of config.json.
* Privacy first: a one-time, 37-language privacy notice explains exactly
  what can be sent to Google before the first translation runs. Decline
  to stay offline and use the local engine instead. The technical
  privacy section in the bundled README.md documents every data path.
* Opt-in diagnostic logging, off by default, with automatic pruning at
  200 MB to protect disk space.

Security hardening included in this release
-------------------------------------------
* DLL search path hardening prevents drive-by binary planting when the
  app is launched from shared or downloaded folders.
* Per-session single-instance handling stops cross-user launch
  conflicts on shared and remote-desktop machines.
* Local-LLM prompt assembly scrubs control tokens, so malicious web
  page text cannot hijack the translation pipeline.
* Oversized clipboard captures are safely clamped before reaching the
  online translation engine.
* Clipboard backups and sampler settings are size- and range-guarded.

Known Issues
------------
* None currently tracked.
